# Relay

An agentic AI customer support application built with Python, LangGraph, RAG, and OpenAI.

## Project Status

Currently under development.

## Planned Features

- AI-powered customer support chat
- Retrieval-Augmented Generation (RAG)
- Tool calling and agent orchestration with LangGraph
- Customer account and billing tools
- Refund eligibility validation and guardrails
- Real-time voice support
- Human escalation
- Observability and evaluation

## Tech Stack

- Python / FastAPI
- LangGraph
- OpenAI
- ChromaDB
- SQLite
- Next.js / TypeScript
